# Project data policy

`data/projects.ts` is the only project catalogue. It models project category, summary, problem, solution, architecture, technical stack, outcomes, and resources.

## Verified portfolio facts

| Project | Verified information |
| --- | --- |
| AI Coding Agent | Streamlit frontend, FastAPI backend, `api.py` deployed on Render, graph orchestration in `graph.py`, and local components required for complete execution. It must not be presented as fully cloud-hosted. |
| RAG-based Chatbot | A deployed live application exists. Its URL has not been supplied yet. |
| Blog Writing Agent | A deployed live application exists. Its URL has not been supplied yet. |
| ML projects | Deployed applications may exist; show live actions only once a real URL is supplied. |

## Data completion

Replace `null` values only with verified details. The UI deliberately omits unavailable actions and sparse claims.
